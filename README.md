# 임고 길잡이북 2027 · 인쇄용 파일

- 쪽수: 24쪽 (표지 4면 + 내지 20면), 중철 제본 기준
- 재단 여백: 사방 3 mm (재단 전 216 × 303 mm)
- 해상도: 300 dpi, RGB (인쇄소에서 CMYK 변환)
- 원본: Figma 「임고 길잡이북 · 구성안」 페이지 (fileKey RZBcCI46r5neevMrWDYbEz, node 65:72)

## 인쇄소에 확인할 것
- 색상: RGB 파일입니다. CMYK 변환 후 남색 배경과 하늘색이 어둡거나 탁해질 수 있으니 교정쇄(가제본)로 확인하세요.
- 표지 용지: 표지와 내지를 다른 용지로 쓰면 표지_4면 / 내지_20면 파일을 따로 넘기세요.
- 안전 여백: 쪽번호와 바닥글은 재단선에서 약 10 mm 안쪽에 있습니다.

## 다시 만들기
Figma에서 수정한 뒤 png300/ 폴더의 쪽 이미지를 다시 내보내고 `python3 build_print.py`를 실행하면 모든 PDF가 새로 만들어집니다.
